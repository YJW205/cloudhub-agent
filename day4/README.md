## 什么是 RAG？

**RAG（Retrieval-Augmented Generation，检索增强生成）** = 让模型"先查资料、再回答问题"。

大模型的知识有截止日期、会幻觉；RAG 把**你自己的文档**变成可检索的"知识库"，回答前先检索相关资料注入提示词——这是企业知识库问答、客服、文档助手的标准技术。

## 学习要点（上午 4h）

- **加载**：读文档（txt / PDF / Word）
- **分割（chunk）**：长文档切成小块，`chunk_size` 和 `chunk_overlap` 的权衡
- **向量化（embedding）**：文本 → 向量，语义相近的文本向量相近（本日用本地中文模型 BAAI/bge-small-zh-v1.5）
- **向量库**：Chroma 本地持久化
- **检索**：问题向量化 → 找最相似的 k 块
- **增强生成**：把检索到的资料拼进提示词 → 模型基于资料回答
