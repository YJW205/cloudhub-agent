## 完整版（推荐）

**云枢 CloudHub 产品文档助手 —— AI Agent 项目**　2026.10

技术栈：Python · LangChain · LangGraph · ChromaDB · BAAI/bge-small-zh-v1.5 · DeepSeek API

项目描述：面向 SaaS 产品（虚构"云枢"）打造企业知识库智能助手，基于 LangGraph 构建 Agent 图，将 RAG 检索、业务工具调用、多轮记忆三种能力统一编排，实现"模型自主决策"的智能问答。

核心工作：
1. **LangGraph 图编排**：构建 `agent ⇄ tools` 条件路由循环（`should_continue` 按 `tool_calls` 决定继续/结束），复用状态推进机制 `Annotated[list, add_messages]` 管理消息流。
2. **Agentic RAG**：将 Chroma 向量检索（bge-small-zh 中文 embedding，512 维）封装为工具，由模型自主判断何时检索，区别于固定流程 RAG；知识库外问题可靠拒绝、不编造。
3. **工具调用与容错**：自定义费用计算、API 错误码查询等业务工具；针对多工具并行调用不稳定，采用 system 约束串行调用 + 异常以 ToolMessage 回传模型自纠重试 + 最大轮数防死循环。
4. **持久化记忆**：基于 `SqliteSaver` checkpoint 实现跨会话多轮记忆，`thread_id` 实现多用户会话隔离。

成果与验证：
- 四类测试问题（文档问答 / 费用计算 / 故障排查 / 知识边界）全部通过，费用计算精确（299×20×12×0.8=57,408 元）
- 故障排查回答输出结构化 5 步排查法，覆盖 HTTPS/公网/事件订阅/状态码等要点
- 知识边界外问题 100% 诚实拒绝（"文档中未找到相关内容"），不产生幻觉

## 面试官可能追问的准备点

- 为什么用 LangGraph 不用手写循环？→ 显式节点、可观测、支持 checkpoint/断点
- 为什么选 DeepSeek？→ 成本低、兼容 OpenAI 协议、中文效果好（项目场景）
- 知识库更新了怎么办？→ 重建索引（build_index.py 一行命令）
- 规模大了怎么办？→ 换更强的 embedding、加 Rerank 精排、多路召回
