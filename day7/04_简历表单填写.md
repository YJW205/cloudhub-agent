## 项目描述（约 800 字，远低于 3000 上限；如需展开可再加"技术难点"段）

**1、项目概述：**
面向 SaaS 产品「云枢 CloudHub」打造企业知识库智能助手。用户可以用自然语言提问产品功能、套餐费用、API 用法与故障排查等问题，系统基于 LangGraph 构建 Agent 图，将 RAG 检索、业务工具调用、多轮记忆三种能力统一编排，由大模型自主决策"查文档 / 算费用 / 直接回答"，实现智能、可溯源、不幻觉的企业级问答体验。

**2、人员分工：**
个人独立完成，从需求分析、架构设计、代码实现到测试验证全流程负责。

**3、我的分工：**
- 基于 LangGraph 构建 `agent ⇄ tools` 条件路由循环（`should_continue` 按 `tool_calls` 决定继续执行或结束），以 `Annotated[list, add_messages]` 管理消息状态流。
- 实现 Agentic RAG：将 Chroma 向量检索（bge-small-zh 中文 embedding，512 维）封装为工具，由模型自主判断何时检索，区别于固定流程 RAG；对知识库外问题可靠拒绝、零编造。
- 设计并注册 3 个业务工具：知识库检索、套餐费用计算、API 错误码查询；针对多工具并行调用不稳定问题，采用 system 提示约束串行调用 + 工具异常以 ToolMessage 回传模型自纠重试 + 最大轮数防死循环。
- 基于 SqliteSaver checkpoint 实现跨会话多轮记忆与 `thread_id` 会话隔离；解决 BGE 模型与 transformers 5.x 版本兼容、HuggingFace 离线加载、DeepSeek 结构化输出格式等生产级问题。

**4、项目成果：**
四类测试问题（文档问答 / 费用计算 / 故障排查 / 知识边界）全部通过；费用计算精确（企业版 20 席位年付 299×20×12×0.8=57,408 元）；故障排查输出结构化 5 步排查法；文档外问题 100% 诚实拒绝。
