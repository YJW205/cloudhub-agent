# 云枢 CloudHub 产品文档（示例知识库，虚构 SaaS 产品，仅用于学习项目）

## 产品简介

云枢 CloudHub 是一款面向中小团队的在线项目管理 SaaS 产品，支持项目、任务、看板、文档、报表五大模块。
支持网页端、iOS 和 Android 客户端，数据实时同步。
云端存储采用 AES-256 加密，符合等保三级要求。

## 计费与套餐

云枢提供三个套餐：
免费版：每月 0 元，支持 3 个项目和 10 个成员，存储空间 1GB。
专业版：每月 89 元每席位，支持无限项目和 50 个成员，存储空间 100GB，含自动化规则和 API 调用。
企业版：每月 299 元每席位，支持 SSO 单点登录、审计日志、专属客户成功经理。
按年付费享 8 折优惠。所有套餐首月免费试用，试用期结束后自动转为对应付费套餐，可在设置中取消。

## 核心功能

项目：创建项目时可选择模板（软件开发、市场营销、人事招聘等）。
任务：任务支持优先级（紧急/高/中/低）、截止日期、附件、评论和子任务。
看板：看板视图支持拖拽，泳道可按成员、优先级或自定义字段分组。
自动化规则：专业版及以上可设置"当任务状态变为已完成时，自动通知负责人"等规则。
报表：提供任务完成率、成员负载、项目进度三类报表，可导出为 CSV 或 PDF。

## API 文档

认证方式：使用 API Key 认证，请求头 Authorization: Bearer <API_KEY>。API Key 在"设置-开发者"页面创建。
基础地址：https://api.cloudhub.com/v1
常用接口：
GET /v1/projects 获取项目列表，支持分页参数 page 和 per_page（默认 20，最大 100）。
POST /v1/tasks 创建任务，请求体必填字段：project_id、title。
GET /v1/tasks/{task_id} 获取任务详情。
PATCH /v1/tasks/{task_id} 更新任务（字段：title、status、priority）。
限流：每分钟 60 次请求，超出返回 429 错误。
错误码：400 参数错误、401 认证失败、403 权限不足、404 资源不存在、429 请求过快、500 服务器内部错误。
Webhook：支持任务创建、状态变更、评论三个事件，在"设置-开发者"页面配置回调 URL。

## 权限体系

项目成员角色分为四种：
所有者：项目创建者，拥有全部权限，可删除项目。
管理员：可管理成员、配置自动化规则、修改项目设置。
成员：可创建和编辑任务、发表评论。
访客：只读权限，只能查看项目内容。
项目可设置公开或私有，私有项目仅成员可见。

## 常见问题与故障排查

登录失败：请确认使用注册邮箱登录；连续 5 次密码错误会锁定账号 30 分钟，可在登录页点击"忘记密码"重置。
无法导出报表：报表导出需要专业版及以上套餐；导出文件会在 24 小时后过期。
Webhook 未收到回调：请确认回调 URL 为 HTTPS 且公网可访问；可在"开发者"页面点击"测试"按钮发送测试事件。
数据同步延迟：网页端数据通常实时同步，移动端受网络影响可能有 1-2 分钟延迟。
API 返回 401：请检查 API Key 是否过期（Key 有效期 1 年），或请求头格式是否正确。
